# Chairman's Climb

You're the chairman of a tenth-tier football club. Hire the coach, run the money, build the ground and the headquarters, buy and sell players — and climb ten tiers to the title. One bad season-end close and the bank ends your career.

## Play

| Device | How |
|---|---|
| **Windows** | [Releases](../../releases/latest) → `Chairmans-Climb-Setup-….exe`. Windows may say *"Windows protected your PC"* — click **More info → Run anyway** (the app isn't signed). |
| **Mac** | [Releases](../../releases/latest) → `Chairmans-Climb-…-mac.dmg`. Open it, drag the app to Applications, then **right-click → Open** the first time ("unidentified developer"). |
| **Android** | [Releases](../../releases/latest) → `Chairmans-Climb-….apk` on your phone. Allow installs from your browser when it asks. |
| **iPhone / any browser** | **https://recisipgg.github.io/chairmans-climb/** — on iPhone tap **Share → Add to Home Screen**; in Chrome or Edge, the install icon in the address bar. Works offline once opened. |

Your careers are saved on your own device. A new release never changes the version you have installed — install the new one when you want it; your careers carry on in it.
